 What happens if you remove the shebang line?

 getting error : ./hello.sh: line 1: Hello,DevOps!: command not found
 This error happens because without the shebang, Linux tries to interpret the file incorrectly and treats the text like a command.

 Single and double quotes:
 echo'$NAME' --> treats everything as text
 echo"$NAME"-->  prints name
